NAME

Lintian::Data::Authority::JavaPolicy - Lintian interface for manual references

SYNOPSIS

    use Lintian::Data::Authority::JavaPolicy;

DESCRIPTION

Lintian::Data::Authority::JavaPolicy provides a way to load data files for manual references.
